# Repository skills

Skills use standard `SKILL.md` frontmatter and link to shared repository knowledge. Keep this repository intact when using them; copying a single folder without its references is not a supported installation.

- [ng-scrm](ng-scrm/SKILL.md): Explain and investigate Northrop Grumman SCRM data, field mappings, hierarchy, metrics, and contextual dashboards from captured source evidence.
- [sisense-compose-plugins](sisense-compose-plugins/SKILL.md): Build or review React Compose SDK analytics components and reusable visualization plugins, including Ogma integrations.
- [ogma-react](ogma-react/SKILL.md): Build and debug Ogma graph visualizations in React, including identity, layout, selection, filtering, and renderer lifecycle.
- [sisense-data-modeling](sisense-data-modeling/SKILL.md): Design or diagnose Sisense model grain, relationships, measures, semantic attributes, and graph query projections.
- [sisense-dashboards](sisense-dashboards/SKILL.md): Build and debug Sisense dashboards, Compose SDK dashboard rendering, filter propagation, contextual analytics, and drilldown.
- [sisense-custom-js](sisense-custom-js/SKILL.md): Create, debug, or migrate Sisense Fusion dashboard and widget JavaScript scripts or add-ons.
- [react-analytics](react-analytics/SKILL.md): Implement and debug React analytics state, query normalization, effects, and imperative visualization integrations.
